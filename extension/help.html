Ultimate Download Manager help

When a download stays in the browser instead of going to Ultimate Download Manager, the toolbar button says why. Each reason below has its fix.

Ultimate Download Manager isn't installed, or its browser connection isn't set up

  1. Install Ultimate Download Manager, or reinstall it. Then start it once.
  2. On its first start, Ultimate Download Manager registers its connection to Chrome, Edge, Brave, Opera, Vivaldi and Firefox.
  3. Restart the browser.

Ultimate Download Manager didn't start in time

The browser starts Ultimate Download Manager when it's closed. A first start or an antivirus scan can make that slow. Open Ultimate Download Manager yourself, then try the download again.

The connection to Ultimate Download Manager failed

Restart Ultimate Download Manager and the browser. If it keeps failing, reinstall Ultimate Download Manager: the installer sets the connection up again.

The download's details are too large

Usually that means very large cookies or a large form. Right-click the link and choose Download with Ultimate Download Manager, or copy the link into Ultimate Download Manager with Ctrl+N.

Ultimate Download Manager is older than this extension

Install the latest Ultimate Download Manager to use everything the extension offers.

Ultimate Download Manager can't take this address

Ultimate Download Manager takes web (http, https) and FTP addresses. Video pages go through the video button, and torrents through magnet links and .torrent files.

Left to the browser by Ultimate Download Manager's settings

Its file type isn't on Ultimate Download Manager's list, its site is excluded, or it's smaller than the minimum size. Hold Alt while clicking a link to keep a download in the browser on purpose.

YouTube and the store's copy of the extension

Browser stores don't allow extensions that download from YouTube. This copy of the extension is installed straight from Ultimate Download Manager, so the video button works there.

Protected video

Netflix, Prime Video, Disney+, Spotify and similar services lock their streams with DRM. Ultimate Download Manager doesn't save those. Use the service's own app for offline viewing.
